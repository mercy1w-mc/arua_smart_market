# ROLE-BASED EXPERIENCE

Implement authentication so that:

```text
SIGN IN
   │
   ├── FARMER ──→ Farmer Dashboard
   │
   └── CUSTOMER ─→ Customer Marketplace
```

The role must be stored and securely enforced by the backend.

The Flutter UI should respond to the authenticated user's role.

A customer should not be able to access farmer management functionality simply by navigating to a route.

A farmer should not be able to access another farmer's private product-management data.

Backend authorization must enforce these rules as well.
